Nebula Drop

Nebula Drop transfers files between your phone and your PC over the local network. The shell serves a page and shows a QR code, so there is nothing to install on the phone.

How it works

Opening Nebula Drop starts a small HTTP server on your machine and displays a QR code pointing at it. Scanning the code with your phone’s camera opens the transfer page in its browser. Files move in both directions from there.

Routes are token-scoped, so the address in the QR code is the only way in, and the page is only reachable from your local network.

Setup

Bind the quickshell:filedrop shortcut — see Keybindings.

Install qrencode first

The QR code is drawn by qrencode, which the installer does not yet pull in. Without it, Nebula Drop cannot show a code to scan:

bash
$ pacman -S qrencode

Both devices must be on the same network

The server binds to your machine’s address on the local network. If the phone is on mobile data, or on a guest network isolated from your PC, the page will not load even though the QR code scans correctly.

Already using KDE Connect?

Nebula Drop is deliberately independent of it. It needs no pairing, no app and no account, which makes it useful for a phone that is not yours — handing someone a QR code is the whole handshake.
